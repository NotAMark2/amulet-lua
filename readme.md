# English

## Amulet Math (Pure Lua)

A pure-Lua port of the math component of the [Amulet](https://github.com/ianmaclarty/amulet) engine, including a set of `table` utilities and additional `math` functions.

The original [Amulet](https://github.com/ianmaclarty/amulet) implements `vec2`/`vec3`/`vec4`, `mat2`/`mat3`/`mat4`, and `quat` as C++ userdata (`am_math.cpp`, `am_mathv.cpp`). This module replaces them with standard Lua tables using metatables, allowing it to run in any Lua runtime without C extensions.



90% of the work was generated by an LLM. I make no secret of that. Even this translation was done using Google Translate.

>"I'm working, but fuck off—just like everyone else here."
(C) A character from the show *Na Nozhakh* (Kitchen Nightmares Russia)

### Compatibility

- Lua 5.1+
- LuaJIT 2.1

### Installation

Copy `amulet.lua` into your project and require it:

```lua
require("amulet")
```
